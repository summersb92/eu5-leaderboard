Making a readable save

    
EU V normally packs its saves into a private binary format. Debug mode makes it write
      plain text instead, which is what this page reads.

    
    
      
  1. In Steam, right-click Europa Universalis V → Properties → General
        → Launch Options, and add -debug_mode.
    2. 
      
  2. Launch the game, load your save and save it again (an autosave works too).
    3. 
      
  3. Optionally remove -debug_mode afterwards — it disables achievements while it's on.
    4. 
    

    

      
Is my save uploaded anywhere?
        
No. This is a static page; the save is read by your own browser, in a background thread, and
          the report is built on your machine. Close the tab and it's gone. The only network requests are
          for this page itself and its fonts.

      
Which browsers work?
        
Any current Chrome, Edge, Firefox or Safari. The game folder is linked for the current visit
          only, so you'll pick it again next time.

      
Why does Chrome say it will upload files?
        
Choosing a folder in a web page always shows that prompt in Chrome, even when, as here, the page
          only reads a few files locally. You can check: this page makes no network requests while building
          a report (open your browser's developer tools → Network).

      
What can I do with the report?
        
Download report saves one self-contained HTML file you can send to anyone — it opens
          in any browser with nothing to install. Download data saves the extracted numbers as JSON;
          drop that file back on this page later to rebuild the report without the save.

      
It says my save is packed
        
The save wasn't written in debug mode. Follow the steps above, then load and re-save it in-game.
          A readable save's first bytes are SAV0200; a packed one starts SAV0203.

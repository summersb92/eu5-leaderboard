Not linked

Steam's default is C:\Program Files (x86)\Steam\steamapps\common\Europa Universalis V — in Steam, right-click the game → Manage → Browse local files to open it. The button works for folders outside Program Files, and Chrome and Edge then remember the folder so later visits only need your save.

Chrome says the folder “contains system files”, or you want it remembered?

Chrome won't let pages open folders inside Program Files. If dragging doesn't work either, give the game folder a second address outside it. Paste this into a Command Prompt or PowerShell window and press Enter — it creates a link, not a copy, and needs no admin rights:

cmd /c mklink /J "%USERPROFILE%\EU5 game" "C:\Program Files (x86)\Steam\steamapps\common\Europa Universalis V\game"

Then click Choose game folder and pick the new EU5 game folder in your user folder (C:\Users\your name) — that one can be remembered. Change the second path if the game is installed elsewhere. Firefox doesn't have this restriction at all.

Making a readable save

    
EU V normally packs its saves into a private binary format. Debug mode makes it write
      plain text instead, which is what this page reads.

    
    
      
  1. In Steam, right-click Europa Universalis V → Properties → General
        → Launch Options, and add -debug_mode.
    2. 
      
  2. Launch the game, load your save and save it again (an autosave works too).
    3. 
      
  3. Optionally remove -debug_mode afterwards — it disables achievements while it's on.

Is my save uploaded anywhere?
        
No. This is a static page; the save is read by your own browser, in a background thread, and
          the report is built on your machine. Close the tab and it's gone. The only network requests are
          for this page itself and its fonts.

      
Which browsers work?
        
Any current Chrome, Edge, Firefox or Safari. Chrome and Edge remember a game folder chosen with
          the button (next visit it links itself, or needs one “Reconnect” click). A dragged folder,
          and any folder in Firefox or Safari, is linked for the current visit only.

      
Can the page just remember where my game is?
        
Web pages are never told real file paths, so there's no path to save. What Chrome and Edge can keep
          is permission to a folder picked with the button — which is why the folder-link trick above is
          worth doing once if your game is under Program Files.

      
Why does Chrome say it will upload files?
        
Choosing a folder with the button always shows that prompt in Chrome, even when, as here, the page
          only reads a few files locally. Dragging the folder in skips it. You can check: this page makes no network requests while building
          a report (open your browser's developer tools → Network).

      
What can I do with the report?
        
Download report saves one self-contained HTML file you can send to anyone — it opens
          in any browser with nothing to install. Download data saves the extracted numbers as JSON;
          drop that file back on this page later to rebuild the report without the save.

      
It says my save is packed
        
The save wasn't written in debug mode. Follow the steps above, then load and re-save it in-game.
          A readable save's first bytes are SAV0200; a packed one starts SAV0203.

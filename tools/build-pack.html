Build a game-data pack

Maintainer tool. After a game patch, point it at the EU V install to pre-render every nation's flag and export the map data, then unzip the result into the repository root and commit it. Reports use the pack matching a save's version, or the newest pack.

The version and name show in-game and in the executable; the Steam build id is in steamapps/appmanifest_3450310.acf.
